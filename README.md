# Portfolio Performance Analysis System

## Overview

The **Portfolio Performance Analysis System** is a Python project developed for **SmartInvest Africa**.
The system analyzes a portfolio of 20 investment assets and provides insights into portfolio value, profit and loss, percentage returns, asset performance, portfolio allocation, concentration, risk flags, and data quality.

## Business Problem

This project addresses:

* Initial investment and current market value
* Profit or loss for each asset
* Percentage returns
* Classify asset performance
* Profitable and loss-making assets
* Portfolio allocation by asset type, sector, and country
* Potential concentration and risk flags
* Quality of portfolio data
* A management-level portfolio summary
* What-if scenarios

### Key Portfolio Observations

* **Green Telecom** recorded the highest percentage return at **16.13%**.
* **Unity Bank** recorded the lowest percentage return at **-6.30%**.
* **Gold Fields** recorded the largest monetary loss at **12,200**.
* **Sunrise Bond** was the largest individual holding by current market value at **262,500**.
* Equity represented **54.75%** of the portfolio's current value.
* Nigeria represented **47.78%** of the portfolio's current value.
* No individual asset exceeded the project's **30% concentration threshold**.

## Business Insights

Based on the fictional dataset, the analysis shows that the portfolio generated a total profit of **174,900**, representing a portfolio return of **5.57%**.

Fifteen of the twenty assets generated positive returns, while five recorded losses.

The portfolio also shows exposure across multiple asset types, countries, and sectors. This allows the system to demonstrate how portfolio analytics can be used to understand performance and allocation patterns.
